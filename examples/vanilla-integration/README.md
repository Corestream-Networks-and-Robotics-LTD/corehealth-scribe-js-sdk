# CoreHealth AI Scribe — Vanilla JS Reference Demo

This working demo shows how an EMR application embeds the CoreHealth AI Scribe UI (Track A Web Component & Track B iFrame) using a secure Node.js backend proxy (Backend Proxy Architecture).

## Running the Demo

1. Start the proxy server:
   ```bash
   node server.js
   ```

2. Open your browser at:
   ```
   http://localhost:3001
   ```

3. Test dictation, click **Accept & Sign**, and inspect the resulting openEHR and FHIR R4 payloads returned to the backend!
